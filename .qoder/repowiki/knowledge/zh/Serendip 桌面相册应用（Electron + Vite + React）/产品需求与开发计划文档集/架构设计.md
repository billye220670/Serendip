本模块为纯文档目录，按功能域组织：
- `原始需求文档.txt`：详情页（沉浸欣赏页）a–j 组件级交互与性能约束的权威需求源。
- `detail-*-dev-plan.md`：基于原始需求的分功能开发计划，如 `detail-lock-mode-dev-plan.md`（单图 pan/zoom 锁定模式）、`detail-thumb-pin-plan.md`、`detail-view-dev-plan.md`，每个文件以“执行方 + 验收标准”格式交付。
- `CanvasPlan/`：画布模式的阶段化拆分，由 `main.md` 总览并链接到 `stage1-completed.md`…`stage7.md` 各阶段完成报告；根目录 `canvas-dev-plan.md` 仅做重定向跳转。
- `stage6-review-design.md` / `stage7-watch-design.md` / `stage8-canvas-design.md`：跨阶段的架构设计评审与 watch/canvas 专项设计。
- `ui-optimization.md` / `canvas-placement-algorithm.md`：通用 UI 优化策略与画布放置算法说明。
- `原型参考(和文档对应).png`：与需求字母编号对应的布局原型图。
依赖方向单向：所有开发计划均引用 `src/renderer/src/views/Detail.tsx`、`CanvasView.tsx`、`canvasMath.ts` 等源码位置作为实现落点，但文档本身不依赖任何代码。
