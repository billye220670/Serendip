根目录作为 Electron 工程的装配点，按 electron-vite 约定组织 src/{main,preload,renderer} 三子模块：
- main/index.ts 是启动入口，在 app.whenReady 中串联 getDatabase → registerThumbProtocol → registerIpcHandlers → scanRoot → startWatcher 的初始化管线，并在 window-all-closed 时反向 stopWatcher/closeDatabase。
- src/main/ipc/contract.ts 定义 IPC 通道常量，src/main/ipc/handlers.ts 集中注册所有 handler；各业务域（scanner、watcher、thumbnailer、recommender、categories、canvases、db）仅通过该契约被调用，形成单向依赖。
- src/preload 使用 @electron-toolkit/preload 注入 window.electron API，屏蔽原生模块直引，使 renderer 只能通过预加载桥访问 IPC。
- src/renderer 以 React + Tailwind + Zustand stores 为 UI 层，stores 通过 window.electron.ipcRenderer.invoke(IPC.XXX) 触发主进程工作流（扫描→入库→生成缩略图→推送变更），渲染层不持有文件系统或 SQLite 句柄。
- plugins 子模块提供轻量插件框架，首个插件 P2V Bridge 通过右键上下文菜单与多选浮条将图片经 IPC 推送到 pix2real 工作流界面，插件开关状态由本地持久化。
- 构建与打包由 package.json scripts 统一编排：dev/start 走 electron-vite，build:win/macos/linux 经 electron-builder 输出平台安装包，tsconfig.node.json / tsconfig.web.json 分别约束主/渲染侧类型检查。
