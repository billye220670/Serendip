模块位于渲染进程，围绕 Zustand store 组织：`stores/plugins.ts` 以 `persist` 中间件把各插件启用状态（`enabled: Record<string, boolean>`）和 P2V 端口持久化到 `serendip-plugins` key；导出 `useP2VEnabled` / `useP2VPort` 便捷 hook。
- 交互层：`hooks/useP2VMenu.tsx` 暴露 `buildP2VItems` / `p2vPickerNode` / `closeP2VPicker`，在 ContextMenu 顶部注入「发送到工作流」子菜单项，并管理 `WorkflowPicker` 的弹出坐标与关闭逻辑。
- UI 组件：`components/WorkflowPicker.tsx` 使用 `createPortal` 挂载到 `document.body`，根据 placement 计算贴边位置，监听 mousedown/contextmenu/keydown/window-move 自动关闭。
- 数据层：`lib/p2vWorkflows.ts` 静态声明 P2V 工作流枚举，供 picker 列表与 toast 显示共用。
- 跨进程边界：选择工作流后通过 `window.api.pluginP2VPush([fileId], wf, port)` 调用主进程 IPC，再由主进程调用 pix2real 的 `external-image-push` 路径版 API 完成推送，返回结果统一走 `pushPluginToast` 反馈。
