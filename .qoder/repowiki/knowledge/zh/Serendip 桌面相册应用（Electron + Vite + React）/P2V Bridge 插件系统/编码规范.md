- 插件开关以 `Record<string, boolean>` 按 id 索引存储，新增插件只需扩展 enabled 初始值与对应 set 方法，无需改动 store 结构。
- 对 store 字段提供语义化便捷 hook（如 `useP2VEnabled`、`useP2VPort`），消费方不直接访问原始 state 键名。
- IPC 调用采用 try/catch + 成功/失败双分支 `pushPluginToast` 的统一错误反馈模式。
- 弹窗类组件一律用 `createPortal` 挂载到 `document.body`，并通过 `data-menu-submenu` 等 data 属性标记 DOM 节点以便外部样式或脚本识别。
