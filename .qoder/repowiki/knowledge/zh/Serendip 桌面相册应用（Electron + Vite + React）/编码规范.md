- IPC 通道名集中在 src/main/ipc/contract.ts 中以字符串常量声明，handler 与 preload 均引用同一份契约，禁止散写裸字符串。
- 主进程按功能拆分为独立 index.ts 模块（scanner/watcher/thumbnailer/recommender/categories/canvases/db），由 main/index.ts 在启动管线中顺序组装，避免跨模块直接互相 import。
- 渲染层通过 window.electron.ipcRenderer.invoke(IPC.XXX) 调用主进程，禁止在 renderer 中直接 require('electron') 或引入 Node 原生模块。
- TypeScript 采用双 tsconfig：tsconfig.node.json 约束 main/preload 侧（允许 Node API），tsconfig.web.json 约束 renderer 侧（禁用 Node API），统一由 npm run typecheck 校验。
