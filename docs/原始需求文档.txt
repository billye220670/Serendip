详情页（沉浸欣赏页）开发规格 

北极星：让用户在本地好好欣赏到被遗忘的图片。屏幕主角永远是当前这张图；其余一切元素默认让位、按需出现、不打扰欣赏。本文档对应布局图中的字母编号 a–i 逐项定义。

全局原则（出现分歧时回此裁决）

大图是绝对主角，任何元素不得在欣赏态抢夺其视觉重心。

滚轮语义唯一 = 切换上/下一张（本页不做 pan/zoom，避免冲突）。

所有 overlay 元素（a/b/e/f/g 等(d除外)）支持"专注态"统一淡出，鼠标移动或按键唤回。

AI/算法（很久后的开发plan现不用考虑）是渐进增强，未就绪时核心欣赏与归类功能必须照常可用。

逻辑干净优先：返回为一键回瀑布流，面包屑下钻不计入任何导航栈。

整体布局

左侧为大图舞台，始终占满可用宽度，不因 d 的出现而收缩。
顶部左侧依次为 a 后退、b 面包屑；顶部右上角为 e 推荐面板开关。
底部左侧依次为 f 喜欢、g 分类胶囊区、h 显示全部分类、i 新建分类。
d 推荐面板为 overlay，浮在大图右侧之上，不占位（大图宽度恒定）。

====================================

组件逐项需求（对应字母编号）

a) 后退按钮
位置：左上角。
行为：点击 = 一键直接返回探索瀑布流（非逐层后退，无导航栈）。
快捷键：Esc 等效。
返回时：触发与进入对称的收缩转场；瀑布流恢复到进入详情页前的滚动位置（要求进入时不销毁瀑布流，仅覆盖其上）。


b) 面包屑导航
位置：顶栏，a 右侧。
内容：当前大图所在路径，按层级切成可点击 segment（盘 > 文件夹 > 子目录 …）。
行为：点击某一 segment，将 d 推荐流的抽选范围收窄/扩大到该层级，原地刷新 d 与接力队列。
同时面包屑导航里当前路径的segment按钮高亮显示。
点击大于app主页根目录的segment忽略，比如主页根目录是c:/user/pic, 那么用户在滚动的时候这个面包屑可能会变成任何这个路径下的文件路径。但用户绝对不能点c:、/user、这两个segment，或者直接视觉灰掉。
重要约束：面包屑下钻不计入任何导航/返回状态（保持 a 的"一键回瀑布流"语义干净）。
路径过长自动换行，不能出现超过到被右侧瀑布流浮层挡住的区域。


c) 沉浸大图（主角 + 滚轮操作区）
呈现：图片完整 fit 居中，深色中性背景衬托，留足呼吸空间。本页不支持 pan/zoom。
滚轮 / 上下方向键 / 空格 = 接力切换上一张 / 下一张（唯一滚轮语义，无歧义）。
切换动效：整图平滑过渡（纵向位移 + 淡入淡出），保持"一张张品"的节奏。
缓冲区 + 回看：已浏览过的图保留在序列中可向上回滚；向下滚过缓冲边界才追加新的相关图。
接力来源 = d 当前推荐模式所计算的相关序列（d 与 c 的"下一张"共享同一队列）。
预加载：预解码下 1–2 张，保证滚动无白屏；离开视口的大图位图及时释放。
视频：在此区内播放（带基础控制：播放/暂停/进度/静音/循环），切走立即停止解码。
backlog（非本期）：看细节需求可后续加"双击 / F 临时 100% 查看"逃生口，不进主交互。


d) 相关推荐面板（overlay，不占位）
位置：浮于大图右侧之上，不挤压大图宽度。
内容：当前面包屑路径范围下的相关图，竖向 mini 流（本期使用通用随机算法；未来可接入 CLIP/Tagger 找相似作为可切换来源）。
视觉克制：窄幅、有限数量（一次 6–8 张，滚动加载更多），不做铺满的对比墙。
交互：
点击任一推荐项，它成为新的当前大图（c），d 与面包屑随之刷新。
快速滚动期间不实时刷新：d 的内容更新做防抖，仅在大图停稳 400–600ms 后刷新一次。
滚动期间 d 保持上一次内容（不闪烁）；停稳刷新时用骨架/模糊占位，缩略图到达后淡入。
进阶：滚动减速时后台预取下一批，做到停稳即现。
默认态：可设为默认收起（零成本）或默认浮出，由 e 控制。


e) 推荐面板开关（唤出 / 收起）
位置：右上角。
行为：在 唤出 与 收起 两态间切换 d 面板；图标随状态切换（收起态显示"唤出"，展开态显示"收起"）。
快捷键：Tab 切换。
不做 hover 热区自动唤出（避免与看图行为误触）。

f) 喜欢按钮
位置：左下角最左。
行为：点亮/点灭切换当前图的"喜欢"状态，即时生效无需确认。
视觉：点亮 = 实心红心 + 已喜欢；点灭 = 描边心 + 喜欢。与划卡模式喜欢视觉统一。
与 g 的分隔：f 右侧用细线 + padding 做视觉隔离。

g) 分类胶囊区（智能子集，支持一图多分类/tag）
位置：f 右侧，底部 overlay。
核心约束：只展示有限的"智能子集（高频或者历史）"（建议 6–8 个），不平铺全部 tag（用户可能有上百个）。
子集填充优先级：
当前图已属的 tag（必须显示，反映归类状态）
最近常用 tag
高频 tag
交互：点击胶囊 = 切换当前图归属（即时生效）。视觉：已属 = 实心高亮；未属 = 描边。
溢出处理：子集容量固定，多余的不平铺，交由 h 全量面板。

h) 显示全部分类（全量搜索面板）
位置：g 右侧。
行为：点击唤出轻量浮层（不离开详情页），承载全量 tag 的搜索与归属管理：
顶部搜索框，自动聚焦，输入即过滤（无视 tag 总数）。
已属 tag 打勾置顶，其余按相关度/最近/字母排序。
键盘流：输入，上下方向键选择，回车切换归属，全程可不用鼠标。
搜不到时回车 = 新建并归入（与 i 行为打通）。
这是解决"tag 很多"的根本手段：把排版问题转为搜索问题。

i) 新建分类按钮（+）注意这一个你可以选择合并在h里。我强烈建议。
位置：g/h 末尾。
行为：当前欣赏场景下直接新建分类并立即将当前图归入（高频心流：刷到图发现没合适分类，当场建）。
去重提示：新建名与已有 tag 近似时提示"已有 #X #Y，确定新建？"，减少同义碎片 tag。
专注欣赏态（全局）
触发：专门快捷键（如 F）或鼠标静止超时（如 3 秒）。
行为：a / b / e / d / f / g / h / i 全部淡出，屏幕仅剩 c 大图，达成极致沉浸。
唤回：鼠标移动或任意按键，UI 淡入。
这是北极星的极致呈现：用户与图独处。


j）缓冲区指示器圆点
比如用户的缓冲区设置为6，那么这里就会有6个圆点，用户永远可以往前回滚6位，再往后回滚也是顺序读取缓冲区，直到往后滚完缓冲区再push进新图片，此时圆点应该在最右侧。你来完善这个逻辑


性能约束（Electron）
大图按显示尺寸解码，绝不在内存常驻多张原图位图，离开视口即释放。
接力预加载上限 1–2 张。
d 推荐缩略图走预生成缓存 + 骨架占位，停稳后单次加载。
d 刷新严格防抖（见 2-d），快速滚动期间零刷新开销。
视频单实例播放，切走立即停止解码（沿用现有 watchdog）。
转场动画走 GPU 合成层，避免主线程掉帧。
边界与异常
当前范围仅一张 / 无相关：d 显示空态；接力流回退到上层目录或全局补充。
文件被外部删除/移动：大图显示失效占位 + 提示，可从队列移除并自动切下一张。
损坏/不支持格式：占位 + 错误提示，不崩溃，可跳过。
tag 数量极多：由 g 智能子集 + h 搜索面板承接，不影响布局。
快速连续滚动：d 防抖，仅末态刷新；c 切换流畅不卡。


明确不做（防止 scope 蔓延）
不做：本页 pan/zoom 画布操作（与滚轮接力冲突，已权衡放弃；细节查看走 backlog 逃生口）。
不做：d 面板做成 Pinterest 式常驻铺满对比墙（抢戏、催走，违背北极星）。
不做：后退做成逐层导航栈（已定为一键回瀑布流，面包屑下钻不计状态）。
暂缓：CLIP/Tagger 找相似作为 d 的可切换来源（本期 d 用通用随机算法）。
暂缓：PureRef 式画布拼贴模式（另一类诉求，记入 backlog）。
验收标准
打开详情页，用户第一反应是"这张图真好看"，而非"下一张点哪个"。滚轮顺滑切图、毫无歧义；想归类时左下角一点即中、tag 再多也能秒搜；想发现下一站时 Tab 一下推荐温柔浮出；想极致沉浸时一键万物归寂。

瀑布流页那侧有两个衔接约定——进入详情页时不销毁瀑布流、仅覆盖其上，并记录当前滚动位置；返回时原样揭开并恢复位置。这两点写在瀑布流页的需求里，否则 a 后退的"恢复滚动位置"会落空。
